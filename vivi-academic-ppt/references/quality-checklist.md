# 交付前自查

## 11 项结构验收

| # | 通过标准 |
| --- | --- |
| 1 | 简洁封面，有配图及出处，不堆方法和统计 |
| 2 | 第二页 Contents，Part 数量/顺序与页序一致 |
| 3 | 每 Part 有简洁扉页，编号和标题准确 |
| 4 | 主标题字号统一，主标题/小标题加粗，结构标签小而浅 |
| 5 | 直接对比优先有框表格，正文与 appendix 都检查 |
| 6 | 引用与他人图文在当前页下方有可读、可追溯出处 |
| 7 | Conclusion 第一张内容页有 RQ 答案和关键数据 |
| 8 | Research Limitation 独立，写实际研究边界 |
| 9 | References 独立，Q&A 另页 |
| 10 | Appendix 完整、简洁，补充证据和图源可查 |
| 11 | 进度正确，正文按 Part、附录独立计算 |

## 研究与叙述

- [ ] 已读研究设计、outline、最终数据与现有文件。
- [ ] 背景解释为什么；RQ 解释研究什么；方法解释如何研究。
- [ ] 每页有中心信息，标题、证据、解释与过渡相互支持。
- [ ] 数据、分母、时段、百分比和百分点准确。
- [ ] 品牌、账号、日期、ID、截图、原始链接对应。
- [ ] 中英摘录准确，引用/改写/翻译归属明确。
- [ ] 对受众、因果、完整性和代表性的结论未超出证据。
- [ ] 装饰图与样本证据分开，来源不是图片搜索页。
- [ ] 标志来源可靠，没有伪造官方素材。

## 视觉与文件

- [ ] 图片等比、重要证据不丢失，正文/表格可编辑。
- [ ] 表格维度一致，字标有留白。
- [ ] 案例是主体，理论和论文依据在下方。
- [ ] 放映尺寸可读，没有靠不断缩字解决拥挤。
- [ ] 纸纹轻且范围正确，appendix 简洁。
- [ ] 出处、页码、进度条、正文末行无重叠，多行来源已放大检查。
- [ ] 目录、扉页、页序、进度、链接目标一致；改页后已重算。
- [ ] 已检查每页最终渲染，并放大检查高风险页。
- [ ] 已保留协作者修改、notes、链接和可编辑对象。
- [ ] 已实际保存、回读，完成声明真实。

脚本只检查部分结构和几何；不能据此声称语义、引用与完整视觉验收通过。

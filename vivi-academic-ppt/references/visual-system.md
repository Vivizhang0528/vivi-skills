# 视觉系统

以 16:9、720 × 405 pt 为参考画布，按输出尺寸换算。优先保持已验证的用户模板。

## 字体

| 元素 | 默认 | 原则 |
| --- | --- | --- |
| 主标题 | Arial 28 pt，Bold | 全篇同字号；过长先改写，不逐页缩字 |
| 内容小标题 | 18–20 pt，Bold | 同层级一致 |
| 正文 | 18–22 pt | 先减文字，再改布局 |
| 案例原文 / 译文 | 中文 16–18 / 英文 14–16 pt | 配对、可编辑，原文优先 |
| 表格与解释 | 14–16 pt | 密集 appendix 可 12–14 pt |
| 结构标签 | 8–10 pt，浅灰蓝 | 小且弱 |
| 来源、图注 | 8–10 pt | 可读、可链接、避开进度条 |
| 页码 | 8–9 pt | 固定位置 |

正文不低于 12 pt。模板原有微型图注可保留，但不能挪用为叙述字号。封面字标是图像，不用替代字体仿造。

## 色彩与纹理

- 暖白背景 `#F2F4F4`；灰蓝标题区 `#DFE7ED`。
- 主要文字 `#26343D`；结构标签 `#8A9BA6`。
- 表头 `#D9E2E9`；边框 `#9AADB9`。
- 进度：未完成 `#C6D3DD`，已完成 `#7D96A7`，当前 `#4C687B`。
- 采用均匀、极淡、哑光的细纸纤维；封面略明显，内页更淡。只作用在原有色块，不覆盖正文或 appendix。
- 生成纹理记录为装饰性 AI 素材，不标成实拍或品牌官方素材。
- 按主题/品牌调整色板，不把灰蓝强加给所有研究。

## 分区

预留底部 30–36 pt 页脚区，再排内容：

- 结构标签约 x40 / y18；主标题约 x40 / y47；细横线约 y91。
- 正文约 x40–680 / y105–365。
- 单行出处约 y371–383，预留文本框实际内边距与行高。
- 页码右下，避开来源行；进度条约 y397，圆点底部不超过 y401，距画布底部约 4 pt。

坐标只是起点。原生表格、内边距、字体替换和多行来源都会改变占位，必须读实际渲染。内容过满时拆页或移至 appendix，不挤页脚。

## 常用版式

| 类型 | 内容顺序 |
| --- | --- |
| Cover | 研究题目、必要身份信息、一到两张有出处的图、留白 |
| Contents | Part 编号和短标题；不放样本数或结果 |
| Part 扉页 | 编号、短标题、可选单图 |
| 案例对比 | 两列有框表格：身份、截图、中英摘录、解释/编码；理论和出处在下方 |
| 统计对比 | 列为对象、行为指标；保留 n、分母、单位、时段 |
| Conclusion 首张内容页 | RQ 对应的答案、数值、一句含义，通常不超过三项 |
| Limitation | 独立页面，三项以内明确边界及影响 |
| References | 完整书目、DOI/原始链接；Q&A 另页 |
| Appendix | 纯色、明确编号、表格或完整文本，沿用正文比较维度 |

## 品牌与图片

优先官方站点/媒体资料；取得困难时用可追溯原始出处的可靠素材。不要把相似字体当作官方 Logo。字标等比放置，按视觉高度匹配，保留留白；正文品牌词保持文字。

多样图片应补充信息：秀场整体、人物、工艺细节、活动/贴文等，避免反复用同一张图或加入无关图片。图片搜索页不是最终出处，应追到作者、品牌或报道。
